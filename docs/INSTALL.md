# 安装与排错

## 一、安装

### 第 0 步：解压到纯英文路径（最容易踩的坑）

> **路径里不能有中文或空格。**
> Chrome / Edge 的文件选择器在非 ASCII 路径上会读不到，报「清单文件缺失或不可读取」。

可以用的位置：

```
D:\cet6-wordbook
C:\cet6-wordbook
D:\Tools\cet6-wordbook
```

**不要**放在「桌面」「下载」「新建文件夹」这类中文目录下面。

判断标准：解压后那一层文件夹里，应该**能直接看到 `manifest.json`**。

### Edge

1. 地址栏输入 `edge://extensions/`
2. 打开 **左下角** 的 **开发人员模式**
   （Edge 的开关在页面左侧栏最下面，不在右上角，这是最常被卡住的地方）
3. 点顶部出现的 **加载解压缩的扩展**
4. 选中 `cet6-wordbook` **文件夹本身** → 确定

### Chrome

1. 地址栏输入 `chrome://extensions/`
2. 打开 **右上角** 的 **开发者模式**
3. 点左上角 **加载已解压的扩展程序**
4. 选中同一个文件夹

> **选文件夹本身，不要点进去选里面的文件。**
> 判断标准：选中的那一层必须能直接看到 `manifest.json`。

### 第 4 步：刷新已打开的网页

装扩展之前就开着的标签页**不会自动生效**，按 **F5** 刷新一次。

### 验证装好了

装成功后，扩展目录里会自动出现一个 `_metadata` 文件夹——**这是浏览器自己生成的**
（它把 `rules.json` 编译成内部规则集），看到它说明加载成功了。

然后点扩展图标，做两项自检：

1. **检测当前页面** → 应显示「已注入，可以正常划词」
2. **检测翻译源** → 应显示「完整档」

## 二、排错

### 加载阶段

| 报错 | 原因 | 解决 |
|---|---|---|
| **清单文件缺失或不可读取** | 选错层级（选成了 `icons` 子目录或上一级） | 重新加载，选中那层要能直接看到 `manifest.json` |
| 同上 | 路径含中文 | 换到纯英文路径 |
| **Cannot load extension with file or directory name _xxx** | 扩展目录里有**你自己放进去的**、以 `_` 开头的文件 | 下划线是浏览器保留前缀。改名或移出扩展目录。（浏览器生成的 `_metadata` 不算，别删它） |
| 图标是灰的、点不开 | 扩展被停用 | 在扩展管理页把开关打开 |

### 划词没反应

**排错第一招**：点扩展图标 → 「**检测当前页面**」，它会直接告诉你原因。

| 原因 | 表现 | 解决 |
|---|---|---|
| **页面在装扩展之前就打开了** | 最常见 | 按 **F5 刷新页面**。每次「重新加载」扩展后也要再刷新一次 |
| 是 PDF 文件 | 浏览器内置 PDF 阅读器 | 注入不可能。用弹窗里的「**快速查词**」：复制文字 → 粘贴 → 查 |
| 是 `edge://` / `chrome://` 内置页 | — | 浏览器不允许任何扩展注入 |
| 是本地 HTML 文件 | `file://` 协议 | 到扩展详情页打开「**允许访问文件 URL**」，再刷新页面 |
| 页面内容在 iframe 里 | 部分在线文档 | 1.1.0 起已支持。若仍不行，重新加载扩展后刷新 |

### 翻译出问题

点扩展图标 → 「**检测翻译源**」：

- **完整档** = 音标、释义、例句、考纲标签都能拿到
- **基础档** = 只拿到译文（说明词典接口被拦，翻译仍可用）

如果是基础档，说明 `declarativeNetRequest` 改写 `Origin` 没生效。

## 三、数据

- 全部存在 `chrome.storage.local`，**不上传任何服务器**
- 只有你主动选中的文字会发给翻译接口（有道 / MyMemory）
- **卸载扩展会清空数据** → 建议定期用「导出 JSON」备份
- 换电脑：导出 JSON，在新机器上用「导入」读回

---

## 四、权限说明

| 权限 | 用途 |
|---|---|
| `storage` | 存单词本 |
| `contextMenus` | 右键菜单两项 |
| `declarativeNetRequest` | 改写请求头，绕过词典接口对扩展来源的拦截 |
| `activeTab` | 「检测当前页面」需要读当前标签页地址（只在点扩展图标时临时生效） |
| 内容脚本匹配 `http / https / file` | 在网页上实现划词，**这是划词功能的前提** |

扩展不读取、不上传浏览内容。
